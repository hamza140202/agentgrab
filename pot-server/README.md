# POT Server (bgutil proof-of-origin provider)

The `ytdlp_pot` method needs Google **proof-of-origin tokens** to look legitimate
to YouTube from flagged IPs. Tokens are generated by running BotGuard in a local
Node VM (Brainicism/bgutil-ytdlp-pot-provider), exposed as an HTTP server on
`127.0.0.1:4416`.

## One-shot

```bash
./setup.sh
```

## Managed by AgentGrab

```bash
agrab pot status --json   # health check (GET /ping)
agrab pot start           # idempotent: clones+builds if missing, launches detached
```

Manual equivalent:

```bash
git clone --single-branch --branch 2.0.1 https://github.com/Brainicism/bgutil-ytdlp-pot-provider.git
cd bgutil-ytdlp-pot-provider/server && npm ci && npx tsc
node build/main.js        # binds 127.0.0.1:4416
```

## Honest limits

- POT tokens **do not guarantee** bypassing the bot gate — on hard-flagged IPs the
  playability gate can fire before token checks. That is exactly why AgentGrab's
  chain has the `loaderto` workhorse tier behind this method.
- The Python plugin side comes from `pip install bgutil-ytdlp-pot-provider`
  (already in requirements.txt); this server is the generation half.
- `agrab doctor` reports POT health but never blocks the chain on it.
